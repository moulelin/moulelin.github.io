def parse_xml_to_dict(self, xml):

        if len(xml) == 0:  # reached the bottom level, return the info for this tag directly
            return {xml.tag: xml.text}

        result = {}
        print("bbb")
        for child in xml:
            print("aaa")
            child_result = parse_xml_to_dict(child)  # recursively traverse the tag info
            print(result)
            
            # if child.tag != 'object':
            result[child.tag] = child_result[child.tag]
            print(result)

Note: the for loop traverses nodes on the same level, e.g. here: <folder>, <filename>, <source>, <owner>, etc.

  • After <folder> has been traversed, it has no child nodes, so we backtrack. Note that we backtrack to the point inside the for loop (where print(“aaa”) is), and result now holds the value after <folder> was traversed, because result is defined outside the for loop. The same applies to <filename>.

  • When we reach <source>, it has children, so the function is called recursively and result starts out empty. Once that for loop finishes, *there is a return that passes result back to where <source> was entered, i.e. the children's result is returned as the value for the parent node <source>.

  • child_result = parse_xml_to_dict(child) # recursively traverse the tag info

  • child_result stores the children's result, while result reverts to the parent node's result.
