Global Scope in the STL

June 29, 2022C++Data Structures

Prefixing :: to C++ functions or namespaces

  • Putting :: before a function, as in ::find(), means it is the global function, not one in the current scope

    Take ::find() here. It is a function from the STL algorithm library. Even without ::, the compiler would look in the global scope if it couldn’t find find locally, but adding it makes the code clearer
