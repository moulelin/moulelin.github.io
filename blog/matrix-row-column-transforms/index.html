Left Multiplication Transforms Rows, Right Multiplication Transforms Columns

December 2, 2022MatrixEnglishRobotics

Why left multiplication is a row transformation and right multiplication is a column transformation

For the matrix product AB=C, the rows of C are linear combinations of the rows of B
Likewise, the columns of C are linear combinations of the columns of A, so right-multiplying by B amounts to applying a column transformation to A.
